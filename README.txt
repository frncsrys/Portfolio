Francis Reyes Portfolio

index.html   The whole site in one file. Open it in a browser with an internet
             connection (it loads fonts and three.js from CDNs). Your 3D character
             is embedded inside it, so nothing else is needed to run it.
character.glb  Your untitled.gltf converted to a single .glb file, for reuse.
untitled.gltf  Your original model file.

To host it, upload index.html to any static host (GitHub Pages, Netlify, Vercel).
