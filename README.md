Open index.html in a browser (needs internet for three.js and fonts).

Put it online with GitHub Pages:
1. Create a new public repo on github.com (e.g. "portfolio" or "<username>.github.io").
2. Upload index.html (and character.glb) to the repo root.
3. Repo Settings > Pages > Source: "Deploy from a branch" > Branch: main, folder: / (root) > Save.
4. After ~1 minute your site is at https://<username>.github.io/<repo>/
